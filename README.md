# Coffeelaktika — полный комплект исходников

Это готовая статическая страница из переписки: лунный фон, пять стаканов,
звёздная орбита, свайпы/перетаскивание и плашка выбранного напитка.
Комплект включает независимый слой мерцающих фоновых звёзд.
Последующие точечные изменения перечислены в разделе «Изменения 22 октября 2026».
Это исходники реализации, а не картинка-макет и не проект на React.

## Как посмотреть

1. Распакуйте весь архив в одну папку, сохранив assets рядом с index.html.
2. Откройте index.html в браузере двойным щелчком.
3. Если удобнее сервер, выполните в этой папке:

   python -m http.server 8020

   На Windows также можно: py -m http.server 8020

4. Откройте http://localhost:8020/.

Установка npm, сборщик, API-ключи, базы данных и серверная часть не нужны.
Изображения локальные. Шрифт Manrope загружается из Google Fonts; без интернета
применится Arial/sans-serif, остальная страница работает с локальными ресурсами.

## Структура

- index.html — полная разметка страницы, шапка, плашка, элементы управления,
  диалоговое окно и встроенный блок мерцающих звёзд перед закрывающим body.
- style.css — исходные стили, адаптивная вёрстка, цвета, размеры стаканов и плашки.
- app.js — круговое движение стаканов и частиц, управление, данные напитков,
  смена плашки и содержимое диалоговых окон.
- assets/moon-background.png — фон без готовой нарисованной орбиты.
- assets/latte.png — латте.
- assets/cherry.png — пряная вишня.
- assets/hazelnut.png — белочка.
- assets/coconut.png — рафаэлло.
- assets/cappuccino.png — капучино.
- background-stars-only.html — только последняя добавка: CSS + JS звёзд.
  Она УЖЕ включена в index.html. Повторно подключать её не нужно.
- reference/approved-desktop.png — предоставленный пользователем референс.
- menu-transcription.txt — расшифровка фото меню; неразборчивые данные помечены.
- CODEX_TASK.md — готовое задание, которое можно передать другому Codex.
- AGENTS.md — ограничения и карта реализации для агента.

## Как работает движение

В app.js переменная phase — общий угол поворота. Его используют и стаканы,
и звёздные частицы орбиты: они вращаются синхронно. Геометрия вычисляется
функцией geometry(). Горизонтальный овал рисуется Canvas 2D; стаканы —
отдельные PNG в кнопках поверх него. Это перспектива с масштабированием,
а не полноценные объёмные 3D-модели стаканов.

- Без наведения общий угол постепенно увеличивается: скорость .105 рад/с.
- Наведение на стакан плавно останавливает вращение всей системы.
- После ухода курсора вращение плавно возобновляется.
- Свайпы, drag, стрелки, точки и нажатие на стакан выбирают напиток.
- При ручном выборе стакан плавно доворачивается вперёд.
- Название, описание, объём и цена синхронизируются с выбором.
- Диалоговые окна и кнопка паузы также приостанавливают движение.
- prefers-reduced-motion отключает автовращение.

Доступен window.coffeeOrbit: select(index), selected, phase, pausedByHover.
select(index) — существующая функция ручного выбора одного из пяти напитков.

## Последний слой звёзд

Он целиком находится в конце index.html и копируется в background-stars-only.html.
Скрипт создаёт #coffee-background-stars ВНУТРИ существующей .background.
70 маленьких звёзд медленно мерцают независимыми CSS-анимациями с периодами
от 6 до 12 секунд и разными задержками.
Нижние 32% исключены, чтобы звёзды не появлялись на лунном грунте.
pointer-events: none не мешает свайпам и наведению на стаканы.
Ни app.js, ни исходный style.css для добавления этого слоя менять не требуется.
При prefers-reduced-motion эти звёзды отображаются без мерцания.

## Что важно при переносе

Сначала запустите проект как есть и проверьте соответствие. Не переписывайте
готовую страницу ради переноса. Сохраните пути assets, размеры, цвета, масштаб
и логику общего угла. Не встраивайте орбиту в фоновую картинку — она уже рисуется кодом.
Встраивая во фреймворк, переносите эту же логику и корректно удаляйте подписки,
ResizeObserver и requestAnimationFrame при размонтировании компонента.

В этой реализации верхние пункты «Напитки», «Десерты», «О кофейне» и «Контакты»
открывают диалоги, а не отдельные URL. Разделение на страницы — самостоятельная
будущая задача, которую нельзя выполнять без запроса пользователя.

Изображения напитков — утверждённые концепт-рендеры. Подписи вкусов не являются
полной официальной рецептурой. Цены взяты из предоставленного фото меню;
места, требующие уточнения, перечислены в menu-transcription.txt.

## Проверка комплекта

Проверены синтаксис app.js и встроенного скрипта звёзд, наличие всех PNG,
целостность ZIP и то, что из исходной страницы добавлен только слой звёзд.
Архив не содержит ключей доступа, .git, служебных настроек публикации и зависимостей.

## Изменения 22 октября 2026

1. Ручное вращение: ввод обновляет общий угол, а стаканы и частицы рисуются
   одним проходом requestAnimationFrame. Размеры и постоянная тригонометрия
   кешируются; передача touch-захвата со стакана на сцену не сбрасывает свайп.
   В локальном headless Edge (1440×1080, DPR 1) p95 обработчика pointermove
   снизился с 30,9 до 0,1 мс, максимум отрисовок за кадр — с двух до одной,
   чтений layout во время тестового перетаскивания — со 158 до нуля.
   Это замеры ввода на данном компьютере, а не гарантия FPS на любом устройстве.
2. Во всех четырёх категориях напитков и в меню десертов добавлены блоки
   «Фото скоро». Они резервируют место для будущей фотографии каждой позиции.
3. Стрелки карусели заменены на SVG и центрируются внутри круглых кнопок.
4. Подпись «Листай и найди свой вкус» под точками удалена.
5. Рядом с «Орёл» используется собственная SVG-стрелка.
6. Существующий единственный слой фоновых звёзд настроен на медленное мерцание
   (6–12 секунд). Фрагмент background-stars-only.html синхронизирован с index.html.
7. Позиции напитков и десертов открывают отдельную карточку поверх меню,
   совпадающую с ним по размеру. В ней три крупные заглушки фотографий,
   листание стрелками, точками, клавиатурой и свайпом, а также шаблонное описание.
   Закрытие возвращает к той же категории и позиции меню. Размеры окон
   ограничены экраном, включая мобильный. Существующие цены и объёмы сохранены.
