# Правила работы с этим комплектом

- Прочитайте README.md и CODEX_TASK.md перед изменениями.
- Сохраняйте исходный дизайн. Последнее разрешённое изменение — только фоновые
  мерцающие звёзды; оно уже включено в index.html.
- Не запускайте новый дизайн, замену ассетов или переписывание на фреймворк
  без явного запроса пользователя.
- app.js: phase управляет и частицами орбиты, и положением стаканов.
  geometry() / drawCups() / paint() / frame() — основные функции анимации.
  go() / update() — ручной выбор и обновление информации.
- CSS звёзд использует уникальный префикс coffee-background-stars,
  keyframes coffee-star-twinkle. Слой находится внутри .background.
- Фон без орбиты: assets/moon-background.png. Орбита рисуется в Canvas.
- Полноценной серверной части и сборки нет. Не требуйте npm install.
- Навигационные кнопки открывают диалоги; это не реализованный многостраничник.
- Не считайте созданные изображения реальными фотографиями продукции.
- Любые изменения должны быть минимальными и проверяемыми по diff.
